Shared npm-package-json-lint config for Nick2bad4u projects.

## Install

```sh
npm install --save-dev npm-package-json-lint-config-nick2bad4u
```

## Usage

Create `.npmpackagejsonlintrc.json`:

```json
{
 "extends": "npm-package-json-lint-config-nick2bad4u"
}
```

## Verification

```sh
npm run release:verify
```
